Ommega 2.4.2

- 修复自动续签漏签：续签线程改用绝对墙钟时间等待，休眠经过的时间不再被跳过（此前 TEE 到期了也不会自动签发）。
- 修复诊断页日志框在暗色模式下浅底白字：补齐从未定义的主题变量，并纠正写错位置的暗色选择器。
- 本版仅 A 端变化，B 端与 Server 无代码改动；自动续签修复需重载 keymint 守护进程。

Ommega 2.4.1

- 修复本地模式下诊断页误显示「当前模式：中继」：改为读取守护进程的 data/relay-mode。
- 修复调试日志总阀切换后「已完成复现，解锁诊断」按钮不立即出现（刷新被节流）。
- 请求异常把 keystore 代理（uid 1017）上的失败归因到真正发起请求的应用，不再被当作系统身份隐藏。
- 共享 uid 的应用（例如 Google Play 服务 10120 / 99910120）能正确解析包名。
- 受管列表之外的应用通过 KernelSU 桥接取真实应用名（如「融合搜索服务」「Google Play 服务」）。
- 诊断测试增至 10 项，覆盖失败归因与共享 uid 解析。

Ommega 2.4.0

- 设置里的诊断改为分级页面：一个调试日志总阀、复现后解锁、七个功能子页（请求异常 / 设备体检 / KeyMint / 注入器 / 中继 / 属性视图 / SOTER），异常按应用聚合显示名称、包名与原因，概览页同步展示。
- 设备体检改为 WebUI 内原生检查；AProbe 作为可选组件打包发布签名版，可一键安装并自动加入属性视图与自动授权策略。
- 指纹签名证书新增签发 keybox 选择：TEE 或 StrongBox 槽位二选一，可直接导入 Samsung StrongBox keybox；槽位缺失时回退并明确提示。
- 认证绑定的指纹签名改由 A 端本地出证，中继模式下不再出现 KEY_USER_NOT_AUTHENTICATED。
- 设备属性视图修复：向 *_for_attestation 发布目标身份、跳过无法改写的长属性、宿主缺失属性不再中断视图（解决部分应用的 -66）。
- 日志控制：总阀同时接管本地与中继的 KeyMint / 注入器等级，新增清除日志、日志轮转上限与 SOTER 详细叙述。
- keybox 槽位与签发 keybox 选择文件的属主统一为 keystore:keystore 0600，导入与启动时自动归一化。
- WebUI 切换更跟手：诊断数据缓存与节流、日志有界读取、应用列表离屏渲染。

Ommega 2.3.1

- 修复 2.3.0 安装后「设置 → 自动化」不可用：模块 ZIP 里有 ommega-rkp，但安装脚本没有解压它。
- 安装脚本现在按 ABI 解压并校验 ommega-rkp，缺失时安装直接失败。
- 仅安装脚本变化，功能与 2.3.0 相同；覆盖安装即可，数据与已签发 keybox 全部保留。

Ommega 2.3.0

- A 端「设置 → 自动化」由浮窗改为完整页面，移除原有的四项 keybox 下载来源，改为导入自备的 CDI 材料包与 keybox（TEE / StrongBox 各自一个槽位）。
- CDI 材料包以 AES-256-GCM 加密保存在本机，模块不内置任何种子或证书；从其它设备拷回的密文会提示无法解密。
- 移植 Duck ToolBox 的 RKP 引擎：可在本机签发新的 TEE / StrongBox keybox，链的级别与 O= 必须与所选槽位一致。
- 新增自动续签：按服务器下发的 time_to_refresh_hours 计算临期，睡到临期时刻再签发；失败后 6 小时内不重试。
- 应用策略页在本地模式下自动隐藏认证签名、本地 keygen EWMA、CPU 与设备属性三张卡片。
- 修复本地模式顶部刷新提示「部分状态无法读取」。
- 修复 keybox 到期时间解析把两位年当成四位年，曾显示成 2611 年。
- 本版仅 A 端变化，B 端与 Server 无代码改动（版本号统一）。

Ommega 2.2.2

- A 端 SOTER 支持按应用分配身份：本地随机 / 导入私钥 / 远程中继，每个应用单独指定；未指定时用默认身份。
- A 端新增 SOTER 总控开关，关闭后所有应用回落到原厂 HAL，分配关系保留；界面移除「重启软件 TA」。
- A 端应用列表新增「SOTER N 次」角标，仅在总控开启时显示，与「证书 N 次」同款样式、不同配色。
- A 端 SOTER 身份管理改走 Rust 管理接口（soter-read / soter-write / soter-import），私钥只在设备端按路径读取。
- 反回滚计数器改为每应用只增不减（带时钟下限），修复微信开通时 counter is not greater than that in server。
- 中继身份按应用生效，支持 UID 映射与跳过 TLS 校验；具名中继不再收到本机账本设备 ID。
- 修复自动认证签名的兼容性回归；看门狗状态备注改为按状态推导。
- 本版只有 A 端模块与界面变化，B 端与 Server 无代码改动（版本号统一）。

Ommega 2.2.1

Ommega 2.2.0

- A 端本地 keygen EWMA 差值目标调整为 85ms。
- Relay 增加证书链/请求字段校验、RKP 后处理、keyblob 版本处理。
